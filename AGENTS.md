## 1. Project Overview

This repository manages the cataloging, restoration (`59.94 fps` optical field-bob deinterlacing via `bwdif=mode=1`), narration, thumbnail generation, and multi-channel publishing pipeline for the **FOX40 Broadcast Archive** (`1,500+` digitized broadcast files from 1973–2018, including `103` historical, sports, true-crime, and California wildfire master reels).

All source `.mov` / `.mp4` broadcast reels and rendered `59.94 fps` master deliverables live on Google Drive (`FOX40_Broadcast_Archive`, root ID `1Br9196213j3f22k9P0p6M-A91X1n0n1d`).

## 3. Mandatory Thumbnail & Channel Page Design Rules (Adam's Spec)

Never revert to split-screens, red/orange clickbait circles over faces, or artificial contrast/sharpening filters on 480i footage. Every thumbnail (`1280x720`) generated by [`scripts/rebuild_best_practice_thumbs_and_pages.py`](scripts/rebuild_best_practice_thumbs_and_pages.py) must follow these rules:

1. **100% Full-Frame Native Broadcast Still (Zero Split-Screen, Zero AI/Plastic Smoothing):**
   * Extract a single full-frame `16:9` crop (`1280x720`) from the `59.94 fps` master at **native broadcast gamma (`Contrast=1.0`, `Color=1.0`, `Sharpness=1.0`)**.
   * Never stack artificial `ImageEnhance.Contrast` / `Sharpness` passes on 480i skin tones (which posterizes midtones into an uncanny/airbrushed look).
   * Always inspect a multi-timestamp contact sheet first to guarantee zero motion blur and zero interlaced field-blend overlaps.
2. **Authentic VCR / Betacam SP On-Screen Display (`PLAY ▶` / `TC ...`) at Top-Left:**
   * Use crisp white VCR monospace typography (`Lucida Console` `44pt`) with a hard black OSD drop shadow and a geometric play triangle `▶` (never rely on Unicode font fallback for `▶` or `●`, which renders as a missing-glyph tofu box `▯`).
3. **2–3 Word Max Condensed Corner Hook at Bottom-Left:**
   * Use heavy condensed block lettering (`Impact` `118pt`) in classic broadcast yellow (`#FFE400`) with a hard black stroke (`6px`) and offset drop shadow (`+9px, +9px`), tucked cleanly into the bottom-left corner (`x=52, y=558`).
   * Keep the bottom-right corner (`x > 1180, y > 650`) 100% clear for YouTube's duration badge (`3:18`).
4. **Banner & Avatar Alignment:**
   * **Spell `DEADSTOCK` as one word** everywhere (`DEADSTOCK TAPES`, `@DeadstockTapes`).
   * **Zero Banner Logo Duplication:** Never place the circular `Deadstock Tapes` badge on the left side of the YouTube banner directly above the circular profile avatar. Keep the banner purely focused on the `DEADSTOCK TAPES` typography, sub-series bar, and darkened archival court/tunnel viewfinder background.
5. **Title Length & Video Duration Strategy:**
   * **Front-Load Titles (`<52 characters`):** Put the star player, sneaker, or crime case in the first 32 characters and place the series name (`| B-Roll & Breds`, `| The Tunnel Tape`, `| The Raw Feed`, `| Case Files`) at the end so titles never truncate on YouTube feeds.
   * **Format Split:** Use `<60s` vertical (`1080x1920`) cuts for YouTube Shorts, TikTok, and Reels; use `2:30–5:00` uncut horizontal (`16:9` / `4:3` pillarboxed) compilations for the main YouTube `Videos` tab.

## 5. Technical Pipeline Rules (FFmpeg + Python)

* **Python Interpreter:** Always use `"C:\Program Files\Python312\python.exe"`.
* **60fps Optical Deinterlacing:** Source NTSC `29.97i` (`2vuy` / ProRes / DV) reels must be field-bob deinterlaced to `59.94 fps` using `bwdif=mode=1:parity=-1:deint=0,fps=60000/1001`.
* **Fast Vertical Blur Canvas:** When rendering `1080x1920` vertical videos from `4:3` masters, never run `boxblur=25:5` at full `1080x1920` resolution; downscale the background layer to `270x480`, apply `boxblur=10:2`, and scale back to `1080x1920` (16x faster).
* **Audio Mixing (`amix`):** Never combine `apad` on the voiceover stream with `amix=duration=first` without `-shortest` (causes infinite padding). Use `amix=inputs=2:duration=first:dropout_transition=2:normalize=0` where input 0 is the fixed-length video audio bed.
* **Windows `edge-tts` DNS Note:** Keep `aiodns` uninstalled in Python 3.12 on Windows 11 so `aiohttp` uses `ThreadedResolver`.
